Her cümlenin ve fonksiyon/blok gövdesinin sonuna ; koyulur. Bu kural, kod yapısını açık ve belirgin kılar.

03 Kurulum Rehberi

CicekliScript; Linux, Windows (WSL 2 veya MSYS2) ve macOS ortamlarında kolayca derlenip çalıştırılabilir. İşletim sisteminizi seçerek adımları takip edebilirsiniz:

Ubuntu, Debian veya Linux Mint Üzerinde Kurulum

Gerekli derleyici ve grafik kütüphanelerini yükleyin:

bash
# 1. Gerekli paketleri kurun
sudo apt update
sudo apt install -y build-essential libcairo2-dev libx11-dev git python3

# 2. Projeyi indirin ve derleyin
git clone https://github.com/drkkahraman/CicekliScript.git
cd CicekliScript
make
sudo make install

# 3. Kurulumu test edin
ccl --version

Windows 10 & 11 Üzerinde WSL 2 (WSLg) Kurulumu

WSL 2, Windows üzerinde yerleşik grafik desteği (**WSLg**) ile gelir. Bu sayede açtığınız GUI pencereleri doğrudan Windows masaüstünüzde bağımsız pencere olarak görüntülenir.

powershell

# Artık hem konsol hem GUI betikleri çalıştırabilirsiniz:

04 VS Code Eklentisi & Dahili Derleyici (.vsix)

CicekliScript dosyalarını (.ccl) Visual Studio Code içinde sıfır kurulumla geliştirebilirsiniz. Resmi VS Code eklentisi CicekliScript derleyicisini kendi içinde gömülü olarak taşır; böylece bilgisayarınıza GCC, Make veya kütüphane kurmadan sadece eklentiyi yükleyerek dili doğrudan çalıştırabilirsiniz!

🚀
Dahili Yerleşik Derleyici (Zero-Setup):

Eklenti kurulduğunda CicekliScript derleyicisi eklenti paketinden otomatik çalışır. Ayrıca editörde sağ tıklayıp "CicekliScript: Dili Sisteme Kur (~/.local/bin/ccl)" diyerek derleyiciyi tek tıkla sisteminize kurabilir ve dış terminallerde de kullanabilirsiniz.

bash
# VS Code komut satırından eklentiyi tek komutla kurun:
code --install-extension vscode-extension/cicekliscript-1.1.0.vsix

Görsel Arayüzden Kurulum ve Kullanım:

  1. VS Code sol kenar çubuğundaki Eklentiler (Extensions — Ctrl+Shift+X) sekmesini açın.
  2. Sağ üstteki `...` (üç nokta) simgesine tıklayıp "Install from VSIX..." seçeneğini seçin.
  3. Proje içerisindeki vscode-extension/cicekliscript-1.1.0.vsix dosyasını belirleyin.
  4. Herhangi bir .ccl dosyası açıp sağ üstteki "▶" (Çalıştır) butonuna basın; kodunuz yerleşik derleyici ile hemen çalışır!
  5. İsterseniz sağ tıklayıp "CicekliScript: Dili Sisteme Kur (~/.local/bin/ccl)" komutunu çalıştırarak dili tüm sisteminizde aktif hale getirin.

05 Kullanım & REPL Kabuğu

CicekliScript'i hem doğrudan betik dosyalarını çalıştırmak için, hem de etkileşimli bir REPL (Read-Eval-Print Loop) kabuğu olarak kullanabilirsiniz:

bash
# 1. Betik dosyasını çalıştırma:
cicekliscript dosya.ccl
# veya kısa takma adıyla:
ccl dosya.ccl

# 2. Argüman aktarma:
ccl script.ccl arg1 arg2 100

# 3. REPL (Etkileşimli Kabuk) başlatma:
ccl
# REPL çıktısı:
# CicekliScript 1.0 (Interactive REPL)
# Çıkmak için 'exit();' yazın.
ccl> cicekli.println("Merhaba Dünya!");
# Merhaba Dünya!
ccl> 15 + 25;
# 40
ccl> exit();

06 Değişkenler, Tipler & Operatörler

CicekliScript dinamik tiplidir; değişken tanımlarken herhangi bir tür anahtar kelimesi (var, int vb.) kullanmanız gerekmez. Değişken adı yazıp değer atamanız yeterlidir. Cümle sonundaki ; zorunludur.

ccl
// Temel Tipler
sayi = 42;             // Sayı (Number - integer veya double)
oran = 3.14159;        // Kayan noktalı sayı
metin = "CicekliScript"; // Metin (String)
aktif = true;          // Mantıksal (Boolean: true / false)
bos_deger = null;      // Boş / tanımsız değer

// Listeler ve Sözlükler
liste = [10, 20, "elma", true];
sozluk = { "ad": "Mete", "puan": 100 };

// Aritmetik ve Mantıksal İşlemler
toplam = sayi + 8;
kombinasyon = (aktif && (oran > 3.0));

cicekli.println("Tip kontrolü:", type(sayi), type(metin), type(liste));
cicekli.println("Sonuç:", toplam, "| Mantık:", kombinasyon);

// Ekrana yazdırma (Satır sonlu / satır sonsuz)

08 Koşul Blokları (if / elif / else)

Koşullar parantez içine yazılır, gövdeler {} ile sarılır. Python'daki elif yapısı desteklenir.

ccl
notu = 88;

if (notu >= 90) {
    cicekli.println("Harf Notu: AA (Mükemmel)");
} elif (notu >= 80) {
    cicekli.println("Harf Notu: BA (Çok İyi)");
} elif (notu >= 70) {
    cicekli.println("Harf Notu: BB (Başarılı)");
} else {
    cicekli.println("Dersi Tekrar Almalısınız!");
};

09 Döngüler (for..in, for(;;), while)

CicekliScript hem Python tarzı koleksiyon gezinimini (for in), hem C tarzı sayaçlı döngüleri (for (i=0; i<n; i=i+1)), hem de while döngüsünü destekler:

ccl
// 1. Python Tarzı for..in ve range()
cicekli.println("--- 0'dan 4'e Sayılar ---");
for (i in range(5)) {
    cicekli.println("Sayı:", i);
};

// 2. Liste Elemanları Üzerinde Gezinme
diller = ["C", "Python", "CicekliScript"];
for (dil in diller) {
    cicekli.println("Öğrenilen dil:", dil);
};

// 3. C Tarzı Sayaçlı for Döngüsü
toplam = 0;
for (k = 1; k <= 10; k = k + 1) {
    toplam = toplam + k;
};
cicekli.println("1'den 10'a toplam:", toplam);

// 4. While Döngüsü & break
n = 3;
while (n > 0) {
    cicekli.println("Geri sayım:", n);
    n = n - 1;
};

10 Fonksiyonlar & Kapsam

Fonksiyonlar hem klasik def sözdizimiyle hem de anonim/birinci sınıf değer olarak cicekli.deffunction ile tanımlanabilir:

ccl
// Standart İsimli Fonksiyon
def topla(a, b) {
    return a + b;
};

// Değişkene Atanabilen Anonim Fonksiyon
kare = cicekli.deffunction(x) {
    return x * x;
};

// Özyinelemeli (Recursive) Fonksiyon
def faktoriyel(n) {
    if (n <= 1) {
        return 1;
    }
    return n * faktoriyel(n - 1);
};

cicekli.println("5 + 7 =", topla(5, 7));
cicekli.println("6'nın karesi =", kare(6));
cicekli.println("5! =", faktoriyel(5));

11 Dinamik Listeler & Dilimleme

Listeler heterojen elemanları tutar. Python benzeri negatif indeksleme ([-1] son eleman) ve dilimleme metotları mevcuttur:

ccl
sayilar = [10, 20, 30, 40, 50];

// Negatif İndeksleme
cicekli.println("İlk eleman :", sayilar[0]);
cicekli.println("Son eleman :", sayilar[-1]);
cicekli.println("Sondan bir önceki:", sayilar[-2]);

// Liste Metotları
sayilar.append(60);
cicekli.println("Eklenmiş liste:", sayilar);

cikarilan = sayilar.pop();
cicekli.println("Çıkarılan eleman:", cikarilan);
cicekli.println("Uzunluk:", sayilar.len());

// Sıralama ve Ters Çevirme
karisik = [5, 2, 9, 1, 7];
karisik.sort();
cicekli.println("Sıralı liste:", karisik);
karisik.reverse();
cicekli.println("Ters liste  :", karisik);

Anahtar-değer eşlemeleri saklar. Değerlere hem nokta notasyonu (sozluk.anahtar) hem de köşeli parantez (sozluk["anahtar"]) ile erişilebilir:

ccl
ogrenci = {
    "isim": "Doruk",
    "bolum": "Bilgisayar Mühendisliği",
    "gpa": 3.85,
    "aktif": true
};

cicekli.println("Öğrenci Adı :", ogrenci.isim);
cicekli.println("Bölümü       :", ogrenci["bolum"]);
cicekli.println("Tüm Anahtarlar:", ogrenci.keys());
cicekli.println("Tüm Değerler  :", ogrenci.values());
cicekli.println("Var mı (gpa)  :", ogrenci.has_key("gpa"));

// Hipotenüs Hesaplama: c = sqrt(a^2 + b^2)
def hipotenus(a, b) {

14 Dosya & Belge İşlemleri (doc.* & file.*)

CicekliScript; diskteki dosyaları okumak, yazmak, ekleme yapmak ve silmek için çoklu değişken desteği ve \n kaçış dizilerini doğrudan destekleyen pratik doc.* modülü sunar:

FonksiyonAçıklama
doc.write(path, ...icerik)Dosyayı oluşturur ve argümanları sırayla yazar (varsa üzerine yazar)
doc.add(path, ...icerik)Dosyanın sonuna yeni veri ekler (append)
doc.read(path)Dosya içeriğini metin (string) olarak okur
doc.delete(path)Belirtilen dosyayı diskten siler (başarılıysa true)
doc.exists(path)Dosyanın var olup olmadığını kontrol eder (true / false)
ccl
dosya_adi = "rapor.txt";
kullanici = "Doruk";
skor = 99.4;

// 1. Dosya Yazma (Çoklu argüman ve satır sonu \n desteği)
doc.write(dosya_adi, "=== Sistem Raporu ===\n", "Kullanıcı: ", kullanici, "\nSkor: ", skor, "\n");

// 2. Dosyanın Sonuna Satır Ekleme
doc.add(dosya_adi, "Durum: Başarılı\n", "Tarih: 2026\n");

// 3. Dosyayı Okuma
icerik = doc.read(dosya_adi);
cicekli.println("Okunan Belge İçeriği:\n" + icerik);

// 4. Dosya Varlık Kontrolü ve Temizleme
if (doc.exists(dosya_adi)) {
    cicekli.println("✓ Dosya mevcut!");
    doc.delete(dosya_adi);
    cicekli.println("✓ Dosya temizlendi.");
};

16 GUI — Pencere ve Grafik Çizimi

CicekliScript yerleşik olarak donanım destekli, çift arabellekli (double buffering) ve Cairo vektör çizim motoruna sahip pencereler sunar. Kodunuzu web IDE üzerinde çalıştırdığınızda çizimler otomatik olarak tarayıcıdaki canvas panelinde render edilir; masaüstünde ise bağımsız yerel bir X11 penceresi açılır.

ccl
// 1. Pencere Oluşturma (Genişlik, Yükseklik, Başlık)
win = cicekli.window(400, 300, "CicekliScript Grafik Çizimi");

// 2. Arka Planı Boya
win.color("#1e1e2e");

// Daire: circle(x, y, yaricap, renk)
win.circle(270, 120, 35, "#f38ba8");

// 5. Olay Döngüsünü Başlat
cicekli.println("Grafik penceresi hazır!");

17 GPU & Tensör Hesaplama Motoru (CUDA) ⚡

CicekliScript, doğrudan NVIDIA GPU donanım hızlandırmalı (CUDA) ve CPU destekli yerel bir Tensör Hesaplama Motoruna sahiptir. Derin öğrenme, bilimsel hesaplama ve matris işlemlerini ultra yüksek performansla gerçekleştirebilirsiniz.

🚀
NVIDIA CUDA Donanım Hızlandırması

Sisteminizde aktif bir NVIDIA GPU (örneğin RTX 5090) tespit edildiğinde, tensör işlemleri GPU çekirdeklerine devredilir ve 1 milyon elemanlı matris çarpımları 1 milisaniyenin altında tamamlanır.

Metot / ÖzellikAçıklama
cicekli.cuda.is_available()Sistemde aktif CUDA GPU var mı kontrol eder (true / false)
cicekli.cuda.device_name()GPU model adını döndürür (Örn: "NVIDIA GeForce RTX 5090")
cicekli.cuda.memory_info()Kullanılabilir ve toplam VRAM miktarını MB olarak verir
cicekli.tensor(liste, [cihaz])İç içe listeden tensör oluşturur (cihaz: "cuda" veya "cpu")
t.matmul(diger) / mm(diger)GPU üzerinde yüksek hızlı matris çarpımı ($A \times B$)
t1 + t2, t1 - t2, t1 * t2Eleman düzeyinde toplama, çıkarma ve çarpma

18 Yorumlar, Kurallar & ';' Disiplini

CicekliScript hem C tarzı hem de betik tarzı yorumları destekler. Kodunuzun sorunsuz derlenmesi için aşağıdaki kurallara dikkat ediniz:

  • Tek Satır Yorum: // Açıklama veya # Açıklama
  • Çok Satırlı Yorum: /* Blok açıklama */
  • Noktalı Virgül (;) Zorunluluğu: Değişken atamaları, fonksiyon çağrıları ve fonksiyon gövdelerinin sonuna ; konulmalıdır.
  • Blok Yapısı: if, for, while ve fonksiyonlar mutlaka {} parantezleri ile sarılmalıdır.
ccl
// Bu bir tek satır yorumdur
# Bu da geçerli bir tek satır yorumdur

/*
   Bu bir çok satırlı blok yorumdur.
   CicekliScript saf C disiplini ile yorumlanır.
*/

x = 100; // ';' koymayı unutmayın!
cicekli.println("x değeri:", x);
