01 Giriş

CicekliScript, yorumlayıcısı sıfırdan saf C (C11) ile yazılmış son derece hafif ve hızlı bir dildir. Dinamik tipler, listeler, sözlükler, dilimleme ve negatif indeksleme gibi Python benzeri özellikler sunarken; blok yapısı ve noktalı virgül zorunluluğu ile C disiplini taşır.

💡

CicekliScript'te her ifadenin sonuna ; konulması zorunludur. Unutulursa derleyici hata verir.

Örnek: İlk Program

cicekliscript
cicekli.println("Merhaba Dünya!");
a = 10;
b = 20;
cicekli.println("Toplam:", a + b);

02 Kurulum

CicekliScript, GCC ve Make ile tek komutla derlenir:

bash
cd /home/admin/cicekliscript
make

Derlenen ikili bin/cicekliscript altında ve ~/.local/bin/cicekliscript yolunda bulunur. Sistem geneli kurulum için:

bash
make install   # /usr/local/bin/cicekliscript

06 Fonksiyonlar

Fonksiyonlar cicekli.deffunction ile tanımlanır. İsimli, anonim (değişkene atanan) veya doğrudan çalıştırılan üç kullanım biçimi vardır.

İsimli Fonksiyon

cicekliscript
cicekli.deffunction topla(a, b) {
    return a + b;
};

sonuc = topla(15, 25);
cicekli.println("Sonuç:", sonuc);

Anonim Fonksiyon (Değişkene Atama)

cicekliscript
kare = cicekli.deffunction(x) {
    return x * x;
};

cicekli.println("5'in karesi:", kare(5));

Anonim Olarak Doğrudan Çalıştırma

cicekliscript
cicekli.deffunction() {
    cicekli.println("Bu blok hemen çalışır!");
}();

07 Koşul İfadeleri

if, elif ve else blokları kullanılır. Tüm blok yapısının sonuna ; konur.

cicekliscript
puan = 85;

if (puan >= 90) {
    cicekli.println("Harf notu: AA");
} elif (puan >= 70) {
    cicekli.println("Harf notu: BB");
} else {
    cicekli.println("Harf notu: CC");
};

08 Döngüler

Python Tarzı for..in

cicekliscript
meyveler = ["Elma", "Armut", "Muz"];
for (m in meyveler) {
    cicekli.println("Meyve:", m);
};

// range() ile kullanım:
for (i in cicekli.range(5)) {
    cicekli.println("İndeks:", i);
};

C Tarzı for(init; cond; step)

cicekliscript
for (i = 0; i < 5; i = i + 1) {
    cicekli.println("Adım:", i);
};

while Döngüsü

cicekliscript
sayac = 0;
while (sayac < 5) {
    sayac += 1;
    if (sayac == 2) {
        continue;
    };
    cicekli.println("Sayaç:", sayac);
};

Döngülerde break; (döngüyü sonlandır) ve continue; (sonraki adıma geç) kullanılır.

Uzunlukcicekli.len(liste);

sayilar = [10, 20, 30];

10 Sözlükler (Maps)

Sözlükler anahtar-değer çiftlerinden oluşur. Hem nokta hem de indeks ile erişilebilir.

cicekliscript
kullanici = {"ad": "Mete", "yas": 25};

// Nokta erişimi
cicekli.println(kullanici.ad);

// İndeks erişimi
cicekli.println(kullanici["yas"]);

// Yeni anahtar ekleme
kullanici.sehir = "İzmir";
cicekli.println(kullanici.sehir);

📐 GUI — Pencere ve Grafik

CicekliScript ile X11 + Cairo tabanlı GUI pencereleri açabilir, metin, dikdörtgen, daire ve çizgi çizebilirsiniz. Online Compiler'da GUI kodlarının çizimleri terminalin altında canvas önizlemesi olarak gösterilir; masaüstü ortamında (X11) ise gerçek bir pencere açılır.

💡

cicekli.window(genislik, yukseklik, "başlık") bir pencere nesnesi döndürür. Tüm çizimler kalıcıdır; window.mainloop() pencereyi kapatana kadar olay döngüsünü çalıştırır (web önizlemesinde bu adım atlanır).

Metotlar

MetotAçıklama
window.color(renk)Arka planı boyar (boş = beyaz; "red", "#1e1e2e", [r,g,b])
window.text(metin, renk, boyut, x, y)Kalın Sans yazısı ekler
window.rect(x, y, g, y, renk)Dikdörtgen çizer
window.circle(x, y, r, renk)Daire çizer
window.line(x1, y1, x2, y2, renk, k)Çizgi çizer (k = kalınlık)
window.clear(renk)Tüm çizimleri siler (renk ile)
window.update() / show()Çizimleri ekrana basar
window.sleep(ms)Bir kare bekler (~60 FPS: 16 ms)
window.mainloop() / run()Olay döngüsünü çalıştırır
window.is_open()Pencere açıksa true
window.close()Pencereyi kapatır
window.get_mouse_x() / get_mouse_y()İmleç konumunu döndürür
window.is_mouse_down()Sol tuş basılı mı?
window.width / heightPencere boyutları

Örnek

cicekliscript
window = cicekli.window(100, 100);

window.color();
window.text("Mete", "red", 16, 20, 35);
window.rect(10, 50, 40, 20, "blue");
window.circle(70, 60, 15, "green");

window.mainloop();
