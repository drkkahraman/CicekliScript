01 Giriş

MeteScript, yorumlayıcısı sıfırdan saf C (C11) ile yazılmış son derece hafif ve hızlı bir dildir. Dinamik tipler, listeler, sözlükler, dilimleme ve negatif indeksleme gibi Python benzeri özellikler sunarken; blok yapısı ve noktalı virgül zorunluluğu ile C disiplini taşır.

💡

MeteScript'te her ifadenin sonuna ; konulması zorunludur. Unutulursa derleyici hata verir.

Örnek: İlk Program

metescript
mete.println("Merhaba Dünya!");
a = 10;
b = 20;
mete.println("Toplam:", a + b);

02 Kurulum

MeteScript, GCC ve Make ile tek komutla derlenir:

bash
cd /home/admin/metescript
make

Derlenen ikili bin/metescript altında ve ~/.local/bin/metescript yolunda bulunur. Sistem geneli kurulum için:

bash
make install   # /usr/local/bin/metescript

05 Girdi / Çıktı

metescript

// Ekrana satır sonu OLMADAN yazdırma
mete.print("Satır sonu yok: ");
mete.println("devamı bu.");

// Kullanıcıdan girdi alma

⚠️
Dikkat

mete.print satır sonu eklemez; mete.println ekler.

06 Fonksiyonlar

Fonksiyonlar mete.deffunction ile tanımlanır. İsimli, anonim (değişkene atanan) veya doğrudan çalıştırılan üç kullanım biçimi vardır.

İsimli Fonksiyon

metescript
mete.deffunction topla(a, b) {
    return a + b;
};

sonuc = topla(15, 25);
mete.println("Sonuç:", sonuc);

Anonim Fonksiyon (Değişkene Atama)

metescript
kare = mete.deffunction(x) {
    return x * x;
};

mete.println("5'in karesi:", kare(5));

Anonim Olarak Doğrudan Çalıştırma

metescript
mete.deffunction() {
    mete.println("Bu blok hemen çalışır!");
}();

07 Koşul İfadeleri

if, elif ve else blokları kullanılır. Tüm blok yapısının sonuna ; konur.

metescript
puan = 85;

if (puan >= 90) {
    mete.println("Harf notu: AA");
} elif (puan >= 70) {
    mete.println("Harf notu: BB");
} else {
    mete.println("Harf notu: CC");
};

08 Döngüler

Python Tarzı for..in

metescript
meyveler = ["Elma", "Armut", "Muz"];
for (m in meyveler) {
    mete.println("Meyve:", m);
};

// range() ile kullanım:
for (i in mete.range(5)) {
    mete.println("İndeks:", i);
};

C Tarzı for(init; cond; step)

metescript
for (i = 0; i < 5; i = i + 1) {
    mete.println("Adım:", i);
};

while Döngüsü

metescript
sayac = 0;
while (sayac < 5) {
    sayac += 1;
    if (sayac == 2) {
        continue;
    };
    mete.println("Sayaç:", sayac);
};

Döngülerde break; (döngüyü sonlandır) ve continue; (sonraki adıma geç) kullanılır.

09 Listeler

Listeler dinamik boyutlu, iç içe geçebilir dizilerdir.

İşlemSözdizimi
Eleman eklememete.append(liste, eleman);
Son elemanı çıkarmamete.pop(liste);
Uzunlukmete.len(liste);
Eleman erişimiliste[0], liste[-1] (negatif indeks)
metescript
sayilar = [10, 20, 30];
mete.append(sayilar, 40);
mete.println("Uzunluk:", mete.len(sayilar));
mete.println("Son eleman:", sayilar[-1]);
son = mete.pop(sayilar);
mete.println("Çıkarılan:", son);

10 Sözlükler (Maps)

Sözlükler anahtar-değer çiftlerinden oluşur. Hem nokta hem de indeks ile erişilebilir.

metescript
kullanici = {"ad": "Mete", "yas": 25};

// Nokta erişimi
mete.println(kullanici.ad);

// İndeks erişimi
mete.println(kullanici["yas"]);

// Yeni anahtar ekleme
kullanici.sehir = "İzmir";
mete.println(kullanici.sehir);
