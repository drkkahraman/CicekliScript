# MeteScript for Visual Studio Code

<p align="center">
  <img src="icons/ms.png" width="128" height="128" alt="MeteScript MS Logo" />
</p>

**MeteScript** programlama dili için resmi Visual Studio Code eklentisi.

Python'ın esnekliği, C dilinin hızı ve zorunlu `;` disiplinini bir araya getiren MeteScript için tam donanımlı geliştirme ortamı!

---

## ✨ Özellikler

- 🎨 **Gelişmiş Sözdizimi Renklendirme:** 
  - `mete.println`, `mete.print`, `mete.input`, `mete.deffunction`, `mete.window` tam desteği
  - Kontrol akışı: `if`, `elif`, `else`, `while`, `for in`, `return`, `break`, `continue`
  - Yerleşik matematik ve dosya fonksiyonları
  - Zorunlu noktalı virgül `;` vurgulaması
- 🏷️ **Özel "MS" Dosya Logosu:** `.ms` ve `.metescript` uzantılı dosyalarınız dosya gezgininde özel modern "MS" logosuyla gösterilir.
- ▶️ **Tek Tıkla Çalıştırma:**
  - Editör başlığındaki **"▶"** (Play) butonu
  - `Ctrl + F5` kısayolu
  - Sağ tık menüsü: **"MeteScript: Dosyayı Çalıştır"**
  - Dosya gezgininde sağ tık ile çalıştırma
- ⚡ **Zengin Kod Snippet'ları:**
  - `println` → `mete.println("Hello World");`
  - `input` → `a = mete.input("Metin: ");`
  - `deffunction` → `mete.deffunction fonk() { ... };`
  - `window` → Eksiksiz GUI pencere şablonu
- 📑 **Otomatik Girinti & Parantez Eşleme:** `{}` blokları ve string otomatik tamamlama.

---

## 🚀 Kullanım

1. Herhangi bir `.ms` uzantılı dosya açın (örneğin `ornek.ms`).
2. Sağ üstteki **"▶"** butonuna basın veya `Ctrl+F5` tuşlayın.
3. Kodunuz VS Code Entegre Terminalinde doğrudan `metescript` ile çalışır!
